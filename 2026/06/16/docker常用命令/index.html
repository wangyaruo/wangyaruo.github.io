一、基础信息类
命令 作用 示例

brew install –cask docker 安装Docker

brew install colima 安装colima，支持非桌面版Docker的运行

colima start 启动Docker

colima stop 关闭Docker

docker –version 查看 Docker 客户端和服务器版本 docker –version

docker info 显示 Docker 系统级详细信息（容器/镜像数量、存储驱动、内核版本等） docker info

docker stats 实时查看运行中容器的资源占用（CPU、内存、网络、磁盘 IO） docker stats

docker system df 查看 Docker 占用的磁盘空间，分镜像、容器、卷、构建缓存 docker system df

docker system prune 清理未使用的镜像、容器、网络、构建缓存（加 -a 会删除所有未使用镜像） docker
system prune -a

二、镜像管理
命令 作用 示例

docker pull <镜像名> 从 Docker Hub 或其他仓库拉取镜像 docker pull nginx:latest

docker images 列出本地所有镜像（REPOSITORY、TAG、IMAGE ID、SIZE） docker images -a

docker rmi <镜像ID/名> 删除一个或多个本地镜像（需先停止并删除依赖的容器） docker rmi nginx:1.25

docker build -t <标签> <路径> 根据 Dockerfile 构建镜像，-t 指定名称:标签 docker build -t myapp:v1 .

docker tag <源镜像> <新标签> 给镜像打一个新标签（常用于推送到私有仓库前重命名） docker tag myapp:v1 myrepo/myapp:v1

docker push <镜像名> 将本地镜像推送到远程仓库（如 Docker Hub、阿里云容器镜像服务） docker push myrepo/myapp:v1

docker image inspect <镜像名> 查看镜像的元数据（层、环境变量、入口命令等 JSON 格式） docker image inspect nginx

docker history <镜像名> 显示镜像每一层的构建命令和大小 docker history nginx:latest

三、容器生命周期（最常用）
命令 作用 示例
docker run <镜像> 基于镜像创建并启动一个新容器（最核心命令） docker run -d -p 80:80 nginx

docker run -it <镜像> <命令> 交互式运行容器（如进入一个 Ubuntu 的 bash） docker run -it ubuntu /bin/bash

docker ps 列出正在运行的容器 docker ps -a（含已停止的容器）

docker stop <容器ID/名> 优雅停止一个或多个运行中的容器（发送 SIGTERM） docker stop my_container

docker kill <容器ID/名> 强制终止容器（发送 SIGKILL） docker kill my_container

docker start <容器ID/名> 启动一个已停止的容器 docker start my_container

docker restart <容器ID/名> 重启容器（相当于 stop + start） docker restart nginx_server

docker rm <容器ID/名> 删除一个或多个已停止的容器（加 -f 可强制删除运行中的） docker rm -f my_container

docker exec -it <容器> <命令> 在运行中的容器内执行命令（常用于进入容器内部调试） docker exec -it my_nginx /bin/bash

docker logs <容器> 查看容器的标准输出日志（支持 -f 实时跟踪） docker logs -f –tail 100 myapp

docker top <容器> 显示容器内运行的进程（类似 Linux 的 top） docker top mysql_server

docker cp <源路径> <容器>:<目标路径> 在宿主机和容器之间复制文件/目录 docker cp ./config.json myapp:/app/config.json

docker rename <旧名> <新名> 给容器重命名 docker rename old_name new_name

docker wait <容器> 阻塞直到容器停止，然后返回退出码 docker wait my_container

docker port <容器> 查看容器的端口映射关系（私有端口对应的宿主机端口） docker port nginx

docker pull ghcr.io/anduin2017/how-to-cook:latest

作用：从指定的 Docker 镜像仓库中下载（拉取）一个镜像到本地。
docker pull：Docker 拉取镜像的命令。
ghcr.io：GitHub Container Registry 的地址（GitHub 官方容器镜像仓库）。
anduin2017/how-to-cook：镜像所属的用户/组织名和仓库名。
:latest：镜像的标签（tag），代表最新版本（通常也是默认的）。

执行结果：本地会多出一个名为 ghcr.io/anduin2017/how-to-cook:latest 的镜像，后续可以用它创建容器。

docker run -d -p 5000:80 ghcr.io/anduin2017/how-to-cook:latest

作用：基于刚刚拉取的镜像，在后台启动一个容器，并把容器内部的 80 端口映射到宿主机的 5000 端口。
docker run：从镜像创建并启动容器。
-d：detach 模式，容器在后台运行（不占用当前终端）。
-p 5000:80：端口映射。将宿主机的 5000 端口映射到容器的 80 端口。
访问 http://localhost:5000 就会访问到容器内运行的 Web 服务（该服务监听 80 端口）。
ghcr.io/anduin2017/how-to-cook:latest：指定要使用的镜像。

执行结果：一个 Web 服务会在后台启动，你可以打开浏览器访问 http://localhost:5000 来使用这个叫做 “HowToCook” 的应用。

查看所有运行中的容器

docker ps

查看当前占用5000端口的进程
sudo lsof -i :5000

或使用 Docker 命令查看是否有容器占用了该端口
docker ps –filter “publish=5000”

停止占用端口的容器
docker stop （ID或者Name）

删除占用端口的容器
docker rm （ID或者Name）

查看本地有哪些 Docker 镜像
docker images
docker images ls
